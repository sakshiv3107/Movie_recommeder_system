# 🎬 Movie Recommendation System

A content-based movie recommendation system built using Python and Streamlit. The application suggests movies similar to the one selected by the user using machine learning techniques.

## 🚀 Features
- Content-based movie recommendations
- Similarity calculation using cosine similarity
- Interactive Streamlit user interface
- Fast and easy-to-use application

## 🛠️ Tech Stack
- Python
- Streamlit
- Pandas
- Scikit-learn
- Pickle

## ▶️ How to Run the Project
1. Clone the repository:
   ```bash
   git clone https://github.com/sakshiv3107/Movie_recommeder_system.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Movie_recommeder_system
   ```
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Run the application:
   ```bash
   streamlit run App.py
   ```

## 📌 Use Case
This project demonstrates a real-world implementation of a recommendation system using machine learning and provides personalized movie suggestions based on user preferences.
